# Совместимость медиаданных

Nelviro получает название, обложку и команды из стандартного Windows SMTC. Эквалайзер использует отдельный WASAPI loopback и показывает общий звук устройства, а не извлекает название из аудио.

## Подтверждённая проверка

На Windows пользователя Opera GX 136.0.6008.111 не публиковала SMTC-сессию при Hardware Media Key Handling = Default. После явного выбора Enabled, перезапуска и запуска YouTube появились Playing, название, обложка и доступность pause/seek. Пользователь подтвердил отображение в острове. Команды pause/seek в этом прогоне не исполнялись.

До изменения API возвращал только Telegram.TelegramDesktop = Stopped. Такой источник в автоматическом режиме больше не выбирается. Играющий источник имеет приоритет; старые обложки при потере источника или ошибке очищаются.

## Границы общего механизма

Это не адаптер только для Opera: все приложения, публикующие SMTC, обрабатываются одинаково. Совместимость других браузеров нельзя считать проверенной только по общему API. Chrome, Edge, Firefox и другие требуют отдельных живых проверок; выключенная интеграция, особенности сайта и версии браузера могут лишить Windows метаданных.

Nelviro не меняет настройки браузеров скрыто. Если метаданных нет, показывается общий звук без чужой обложки и неподдерживаемых команд. Ручной флаг Opera — диагностическое исправление конкретного окружения, а не универсальное требование к установке Nelviro.

Работа при отключённой SMTC-интеграции потребует отдельного браузерного модуля с явными разрешениями. Такой модуль и извлечение браузерного видеопотока пока не реализованы. Захват заголовка окна или изображение браузера не подменяют метаданные ролика.

Документация API: https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmanager
