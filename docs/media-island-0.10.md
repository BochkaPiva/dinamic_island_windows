# Медиасценарии 0.10

> Ниже описан прототип 0.10.0. В 0.10.2 меню ▷, инструкция PiP и публичный выбор DWM-превью убраны. Локальные файлы, продолжение, камера и закрепление карточки доступны в настройках: «Остров → Видеофайл и камера». Извлечение браузерного видео внутри острова не реализовано. Медиаданные браузера зависят от его интеграции с Windows; отсутствие метаданных отображается как «Звук Windows», без старых обложек и команд.

## Как пользоваться

В раскрытом острове нажми ▷: видеофайл, предпросмотр окна, зеркало, закрепление карточки. Те же действия доступны в настройках острова. Перетащи верхнюю полосу видео или зеркала, чтобы переместить окно. Размер базового медиасостояния — 480×320 логических пикселей, с ограничением рабочей областью экрана.

Пауза видеофайла возвращает остров к рамке и сохраняет позицию; продолжение — через ▷ → «Продолжить видео». Крестик завершает источник, Esc делает то же самое. Возврат использует тот же HWND: положение и размер интерполируются с текущей точки, содержимое движется вместе с оболочкой. Прервать раскрытие закрытием можно в любой момент. Настройка уменьшения анимаций применяется к переходам.

Горизонтальное перетаскивание компактного острова или горизонтальная прокрутка тачпада переключает музыку, часы и запущенный/приостановленный таймер. Вертикальное колесо управляет громкостью Windows. Короткий щелчок раскрывает панель. Выбор карточки действует 20 секунд, затем возвращается автоматический приоритет; подписчик может закрепить карточку через ▷. Завершение таймера не переключает трек. В медиасостоянии сигнал таймера получает отдельную строку с остановкой сигнала.

## Доступ

Бесплатны прежняя чёлка, поиск, заметки, таймер, две активные группы и базовое перелистывание. Подтверждённая подписка открывает плавающую форму, дополнительные группы, закрепление карточки, видео и зеркало. Проверки находятся в контроллере перед запуском ресурса. Действующий подписанный Telegram permit уже открывает эти возможности, изменения сервера не требуются. Завершение доступа освобождает активный расширенный источник и возвращает бесплатную форму, сохраняя пользовательские данные.

## Что именно делает видео

Локальный файл воспроизводится QMediaPlayer. Меню звука позволяет выбрать устройство именно для этого видео. Другие приложения не перенаправляются скрытым образом. Выбор глобального устройства/громкости открывает штатные настройки Windows. Аудиопульт также позволяет явно выбрать SMTC-приложение или автоматический источник; неподдерживаемые команды по-прежнему отключены.

Предпросмотр окна — системная DWM thumbnail-связь, без записи и screenshot polling. Окно выбирается вручную; доступ проверяется по HWND/PID, системные API используют отдельные ctypes DLL-объекты. Панель показывает клиентскую область с сохранением пропорций. В исходное окно переходит только кнопка «К источнику». Это не управление кликами внутри копии чужого окна и не извлечение потока видео из сайта. Во время выбора можно явно связать превью с SMTC-плеером; только тогда его пауза возвращает остров. Без этой связи завершение/пауза чужого плеера не угадываются по заголовку.

Свёрнутый источник получает понятное состояние и кнопку возврата. Защищённые окна могут отображаться чёрными: защиты не обходятся, универсальная поддержка стриминговых сервисов не заявляется. DWM не даёт приложению надёжного сигнала, что чёрная картинка является запретом захвата, а не самим содержимым; это ограничение явно показывается перед выбором. Это первая версия предпросмотра целого клиентского окна, без автоматического выделения прямоугольника видео во вкладке.

## Ресурсы и поведение

Видео и зеркало создают QtMultimedia-объекты по запросу. Камера не подключает микрофон и ничего не записывает. Её закрытие, ошибка/остановка устройства, завершение доступа и выход приложения останавливают устройство. При нескольких камерах есть выбор; при неопределённом разрешении используется Qt permission API. Отказ Windows не запускает устройство. Для зеркала предпочитается формат до 720p/30 fps.

Кадры читаются из последнего кадра QVideoSink таймером не чаще 30 раз в секунду, без Python-слотов на каждом кадре декодера. В UI остаётся одно изображение до 1280×720. Таймер чтения выключается при паузе/закрытии; камера освобождается немедленно. Локальный файл на паузе сохраняет decoder/source для продолжения, явное закрытие очищает source. Неудачная загрузка видео/камеры ограничена 10 секундами. DWM-предпросмотр отслеживает доступность источника раз в 500 мс; связь сохраняется только на время короткого обратного перелёта и освобождается в конце.

Явно открытое медиа — закреплённый режим: обычное уклонение и автоматическое полноэкранное скрытие его не перемещают. Ручное скрытие/приостановка приложения закрывают источник. После возврата снова действует обычная политика скрытия в полноэкранном режиме. При отключении монитора положение пересчитывается в существующую рабочую область, при закрытии возвращается к выбранному в настройках экрану.

## Проверка кандидата

Автоматические тесты проверяют права до запуска, настоящее декодирование тестового AVI, паузу/продолжение, очистку source, прерывание раскрытия, непрерывный возврат того же HWND, потерю окна/камеры/доступа, неизменность групп, жесты без команд плееру, удержание выбранного медиаприложения и ограничение рабочей областью.

Отдельная native-проверка создаёт реальное окно-источник, проверяет цветные DWM-пиксели в композиции рабочего стола и воспроизведение файла, затем перемещает и возвращает тот же HWND. Физическая камера пользователя в этой проверке не включается. Её реальный preview, конкретные браузеры/DRM-сервисы, Bluetooth-устройства, HDR и несколько физических мониторов требуют пользовательской/аппаратной проверки; это не заменяется mocks и не заявляется как уже проверенное.
