# Ярлыки в группах

Раньше группа содержала путь к исходному ярлыку: удаление значка с рабочего стола
делало эту ссылку недоступной. Начиная с 0.4.2, `.lnk` и `.url` копируются без
изменения содержимого в `%LOCALAPPDATA%\Cloud Island\shortcuts`.
Аргументы запуска, рабочая папка, пользовательская иконка и URL остаются прежними.
Документы, программы и папки по-прежнему добавляются ссылками на исходные пути.

Перед удалением исходного значка программа сохраняет файл и манифест библиотеки,
атомарно записывает группу и повторно сверяет SHA-256 обеих копий. Убираются только
ярлыки непосредственно из пользовательского или общего рабочего стола. Ярлыки
меню «Пуск» и прочих папок сохраняются на исходном месте. Ошибка копирования,
записи или проверки оставляет исходник на месте. При отсутствии прав на удаление
группа остаётся рабочей, а программа сообщает, какой значок убрать не удалось.

Существующий список резервируется в `desktop-groups.before-shortcuts.json`.
Манифест `shortcut-library.json` сохраняет исходный путь и хеш каждой копии.
Удаление группы убирает её записи, но сохраняет файлы библиотеки; вернуть значок
можно через контекстное меню элемента или открыть библиотеку из настроек.
Резервная копия данных приложения должна включать и эту папку, и манифест.

Отключение сбора значков сохраняет рабочую копию на столе при последующих
добавлениях; уже убранные значки автоматически не возвращаются.

## Иконки и движение

Иконки извлекаются по индексу системного списка изображений: `SHGFI_ICON` для
ярлыка добавлял стрелку к самому изображению. Для наших элементов используется
`SHGFI_SYSICONINDEX`, затем `SHGetImageList` и `ImageList_GetIcon` без overlay-флагов.
Системные списки не изменяются, собственные HICON освобождаются, интерфейс
IImageList получает Release. Получение выполняет один фоновый поток, GUI получает
QImage и создаёт QIcon; кеш ограничен 256 изображениями.

Пиксельные дельты тачпада применяются напрямую, без дополнительного сглаживания.
Дельты колёсика задают ограниченную цель, к которой движется критически затухающая
пружина с непрерывной скоростью. На границах, при перетаскивании полосы и скрытии
содержимого движение останавливается; в покое таймер не работает.

Основания: [SHGetFileInfoW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetfileinfow),
[SHGetImageList](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetimagelist),
[QWheelEvent](https://doc.qt.io/qt-6/qwheelevent.html).
